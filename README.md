# Assessment_of_cv_to_vacancy_fit
Курсовая работа по Технологии разработки программных систем, в рамках которой проектируется и разрабатывается "Система интеллектуального анализа соответствия резюме требованиям вакансии".


## Состав

| Каталог | Что внутри |
|---|---|
| `frontend/` | Веб-клиент (React, Vite, TypeScript), отдаётся через nginx |
| `backend/` | Сервер (FastAPI): API, сбор вакансий, подбор, работа с PostgreSQL и моделью |
| `models/` | Локальные веса `rubert-tiny2` (не в git, скачиваются `make models`) |
| `docker-compose.yml`, `.env.example` | Запуск всей системы; значения берутся из `.env` |

## Что готово

- **Веб-клиент**: регистрация и вход, личный кабинет, загрузка резюме (PDF/DOCX), подбор вакансий с фильтрами, страница вакансии с таблицей «требование / цитата / статус», избранное.
- **Сервер**: аутентификация и сессии, загрузка и обработка резюме, подбор, избранное, сборщик вакансий с trudvsem (планировщик, инкрементальные и полные запуски).
- **PostgreSQL + pgvector**: 22 таблицы, миграции (`backend/app/db/migrations`), репозитории на `asyncpg`. Хранилище в памяти осталось для быстрых тестов.
- **Би-энкодер `rubert-tiny2`**: векторы вакансий и резюме, отбор кандидатов через HNSW-индекс, пересчёт только изменённых вакансий и при смене версии модели.
- **Текст вакансий**: единая нормализация, выделение требований со спанами, нарезка резюме на фрагменты по инструкции разметки (базовые правила).
- **Проверено**: на 20 000 реальных вакансий (≈133 вакансий/с, recall@300 = 0,994), нагрузка на 100 000 (p95: подбор 405 мс, страница 120 мс, вакансия 185 мс), 182 теста на memory и 110 на PostgreSQL, сквозной прогон через curl.
- Подробности и принятые решения: `backend/REPORT.md`, проект БД: `db_design.md`.

## Как запустить

```bash
cp .env.example .env        # задайте пароль БД
cd backend && make models   # скачать rubert-tiny2 в ../models (нужна сеть)
cd .. && docker compose up --build
```
Клиент: `http://localhost:8080`, письма: Mailpit на `http://localhost:8025`, БД для pgAdmin: `127.0.0.1:55433`.

Тесты, нагрузочные и сквозные проверки вынесены из репозитория (см. `cv_vacancy_fit_dev_tools/README.md` рядом с ним).
